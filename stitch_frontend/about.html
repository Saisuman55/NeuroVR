── MODEL ARCHITECTURE ──

bolt

EfficientNet-B4

Compound scaling for optimal depth/width/resolution. Pre-trained on ImageNet. Custom classification head with dropout. Two-phase training (frozen backbone, then fine-tuning).

straighten

Input / Loss (Classifier)

  • 380x380 RGB tensors
  • Albumentations (ShiftScaleRotate, GridDistortion)
  • Loss: CrossEntropy
  • Metric: Accuracy
account_tree

U-Net + ResNet34

Classic encoder-decoder architecture with skip connections. ResNet34 encoder pre-trained on ImageNet. Implemented via segmentation_models_pytorch.

straighten

Input / Loss (Segmenter)

  • 128x128 RGB tensors
  • Loss: BCE + Dice Loss (hybrid)
  • Metrics: Dice Coefficient, IoU
